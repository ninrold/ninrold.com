# Ninrold

Ninrold is a personal website for projects, ideas, tools and experiments.

## Sections

- **Arquitectura** — portfolio, references, resources and tools.
- **Derecho** — subject areas and a growing reference library.
- **Juegos** — small browser games built with HTML, CSS and JavaScript.

## Technology

The site is intentionally built as a lightweight static website. Pages use native HTML, CSS and JavaScript and are published with GitHub Pages on the custom domain `ninrold.com`.

## Project structure

Each section lives in its own directory and uses an `index.html` entry point. Shared site-wide assets can be added under `assets/` as the project grows.

## Development

No package manager or build step is currently required. Edit the relevant HTML file and preview it in a browser. Changes merged into the publishing branch are deployed through GitHub Pages.

## Guiding idea

Ninrold is a personal, evolving space. Its sections can have distinct purposes and visual details while sharing a coherent identity.
